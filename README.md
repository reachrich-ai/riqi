# RiQi

RiQi 是 ReachRich 的 A 股投研助手，用于整理公司研究材料、核对来源和梳理后续研究问题。

[打开 RiQi](https://riqi.ai/) · [产品介绍](https://reachrich.ai/riqi) · [使用手册](https://docs.reachrich.ai/)

## 从一个问题开始

不要只问一家公司“好不好”。先说明你正在判断什么、手上有哪些材料，以及希望比较哪段时间。

提问时可以带上这几项：

- 公司名称与证券代码
- 本次研究问题与观察期限
- 原始材料链接、发布日期与事件日期
- 已经核实的事实
- 还需要核实的假设
- 希望下一步比较的资料
